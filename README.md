# 西条酒蔵通り 観光案内WEBアプリ

## ページ構成

- `index.html`：公式ポータル風のホーム
- `map.html`：徒歩ルート案内マップ
- `guide.html`：7酒蔵・くぐり門・JR西条駅の案内
- `products.html`：各酒蔵の商品例と公式商品ページ
- `nearby.html`：観光案内所、トイレ、休憩、文化施設

## マップの主な改善

- 道路を太く白くし、背景との境界を灰色の縁で明確化
- 選択中の案内ルートを太い青線、白い縁、影、矢印で表示
- JR西条駅、7酒蔵、くぐり門の全組み合わせで徒歩ルートを表示
- 酒蔵案内・商品紹介ページから、対象施設を地図で直接開ける
- `map.html?from=saijo-station&to=kamotsuru` のようなURLでルートを直接表示
- GPS現在地は酒蔵エリア内の場合のみ出発地として利用
- 車・電車・飛行機などの起動演出は使用しない安定版

## 起動方法

GPSとPWAを正しく動かすにはHTTPSまたはlocalhostで開いてください。

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

## 情報更新

商品、営業時間、試飲、設備情報は変更されるため、各ページから公式サイトを確認してください。現地調査で確認できていないバリアフリー設備は断定表示していません。

## 音読さんMP3

`assetsaudio` フォルダーに既定のファイル名でMP3を入れると、マップ詳細画面から再生できます。


## ロゴ

提供された「西条酒蔵 / SAIJO SAKE BREWERIES / 水と伝統」ロゴを、全ページの共通ヘッダー、フッター、ブラウザアイコン、PWAアイコンへ反映しています。


## スタイリッシュ版の変更

- ヘッダーと各ページのヒーローはキャッチコピーをなくし、タイトルだけに整理
- ロゴの濃紺と橙色を基準にした統一デザイン
- 周辺スポットを地図マーカー・場所一覧・徒歩ルート検索へ追加
- 周辺スポットページの各カードから、地図上の該当場所を直接開けます


## ホームメイン画像

ホームのメインビジュアルを、提供された西条酒蔵通りの路地写真へ変更しました。画像は表示速度を保つためWebPに最適化し、スマートフォンとパソコンで見切れにくい位置へ調整しています。
